The Six Criteria

A system qualifies as a PCE only if it meets all six:

01

User-owned

The agent is yours; it exists without any vendor account

02

Thinks locally

Core reasoning runs on the user's own device

03

Long-term memory

It remembers you across days, months, years

04

Architecture-level privacy

Enforced by design, not by promise

05

Cross-ecosystem neutral

Not locked to any vendor's ecosystem

06

Runs on hardware you already own

No new phone required

PCE是什么

PCE——个人认知外骨骼（Personal Cognitive Exoskeleton）：一个属于你的AI。它在本地思考、长期记得你、隐私由架构保证而非承诺保证、跨生态中立、跑在你已经拥有的硬件上。

站位：我们不是操作系统，也不是又一个Agent平台。PCE不与OS争位、不与Agent争位、不与云争位——它只站在用户身边。你想用什么，它就替你去用。强化一切，取代无物。 判据只有一条：主权和记忆归用户。

六判据

①用户拥有 ②本地思考 ③长期记忆 ④架构级隐私 ⑤跨生态中立 ⑥跑在你已有的硬件上——不需要为AI换一台新手机。
